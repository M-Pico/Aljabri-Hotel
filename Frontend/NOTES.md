# شرح ملفات مشروع فندق الجابري

1. page.tsx: يمثل الصفحة الرئيسية.
2. layout.tsx: الهيكل العام المشترك للصفحات.
3. globals.css: التنسيقات العامة.
4. public: نضع فيه الصور والشعارات والأيقونات.
5. package.json: يحتوي على معلومات المشروع والحزم والأوامر.


## Routing and Navigation    1
- كل مجلد داخل app يمثل مسارًا.
- ملف page.tsx داخل المجلد يمثل الصفحة.
- نستخدم Link من next/link للتنقل بين صفحات الموقع.
- href يحدد عنوان الصفحة المطلوبة.


## Client Components و Server Components    2
1. Server Component:
- النوع الافتراضي في Next.js.
- نستخدمه لعرض المعلومات والمحتوى.
- لا يستخدم useState أو onClick مباشرة.

2. Client Component:
- نستخدمه للعناصر التفاعلية.
- يسمح باستخدام useState و onClick.
- نكتب "use client" في بداية الملف قبل الاستيرادات.

ملاحظة:
يمكن استخدام النوعين معًا في المشروع حسب الحاجة.




##    ما الفرق بين Global CSS و Tailwind         3             
- Global CSS: نكتب فيه قواعد CSS عامة يمكن استخدامها في جميع صفحات الموقع.
- Tailwind: نكتب كلاسات التنسيق مباشرة داخل عناصر JSX.

##    ما الفرق بينه وبين Global CSS             4
- globals.css: تنسيقات عامة تؤثر على الموقع كله.
- page.module.css: تنسيقات خاصة بصفحة أو مكوّن محدد، ولا تتعارض عادةً مع تنسيقات الصفحات الأخرى.


* لاحظي الفرق المهم
- في Tailwind نكتب:  className="text-2xl"
- أما في CSS Modules نكتب: className={styles.title}
